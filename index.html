01 / About

教育と研究の現場で使いたくなる道具を。

Stücke 110 は、教育に携わる人と研究者のためにつくったアプリのシリーズです。

ひとつのアプリに何でも入れるのではなく、それぞれが自分の役目に必要な機能だけを持っています。計画は Plan、記録は Note、分析は QDA、文献は Reviewer。道具どうしがつながり、シリーズ全体でひとつの仕事場になることを前提に設計しています。

押したとき、動かしたときの手触りを大切にして、毎日ひらきたくなるものを目指しています。

03 / Flow

4つの道具でつながる研究の流れ。

計画して、記録を取り、分析して、読む。どこから使い始めても、ほかの道具とつながります。

  1. 01 · 計画する

    110 Plan

    授業やインタビューの予定を、週案で組み立てる。

  2. 02 · 書き起こす

    110 Note

    話されたことを、逐語録にする。

  3. 03 · 分析する

    110 QDA

    逐語録や記述に、コードを付けて読み解く。

  4. 04 · 読む

    110 Reviewer

    先行研究の論文を、問いを見失わずに読む。

04 / Scenes

こんな場面で

授業研究をする先生

Plan で単元と発問を組み、授業のあとの子どもの記述を QDA で分析。予想される反応と実際を並べて、次の授業につなげます。

Plan · QDA

質的研究をする大学院生・研究者

Plan で調査やインタビューの予定を週ごとに組み、Note で逐語録に、QDA でコードを付けて整理。先行研究は Reviewer で、自分の問いを横に置いたまま読みます。

Plan · Note · QDA · Reviewer

教育実習生

Plan の初期設定で「実習生」を選ぶと、実習期間の授業と ToDo を、一週間ごとに見わたせる手帳になります。

07 / FAQ

よくある質問

Mac と Windows のどちらで使えますか？

どちらでも使えます。動作環境はダウンロードページをご覧ください。

インターネットにつながっていないパソコンでも使えますか？

使えます。どのアプリも通信を一切しないので、データが外に送られることはありません。学校や研究室の端末に入れられるかどうかは、それぞれの管理者のきまりに従ってください。

はじめて開くときに警告が出ます。

開発元の署名をまだ付けていないためです。Mac では、アプリを右クリックして「開く」を選びます。Windows では「詳細情報」から「実行」を選びます。

データはどこに保存されますか？別のパソコンに移せますか？

あなたのパソコンの中だけに保存されます。110 QDA はプロジェクトが .qda ファイル1つなので、コピーするだけで移せます。各アプリには、バックアップの書き出しと戻す機能があります。

アプリは自動で更新されますか？

自動更新はありません(通信しないためです)。新しい版は、お知らせとダウンロードページでご案内します。

問い合わせはどこからできますか？

お問い合わせフォームからお送りください。不具合のご報告には、製品名と版、Mac か Windows かを添えていただけると助かります。公式 LINE では、新しい版のお知らせをお届けしています。
